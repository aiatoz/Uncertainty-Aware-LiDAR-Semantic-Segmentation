# PNPP_v2 — uncertainty-aware PointNet++

PointNet++ (Qi et al., NeurIPS 2017, single-scale-grouping segmentation network) trained with and without the model-independent epistemic uncertaint `u_tilde` from the ANN pipeline.

PNPP_v2 uses some of the intermediate blocks generated by the RandLA-Net pipeline instead. So blocks from RandLA-Net are prerequisites, kindly run the same first. With the same seed, PointNet++ and RandLA-Net are trained on identical blocks.

Running files in `tests/` before the actual notebooks are advised.

## Structure

```
configs/        # Hyperparameters and dataset config files
src/            # Entire reusable logic or modules
notebooks/      # Notebooks per pipeline stages
tests/		# Files to ensure the modules are working fine
```

**Before the first training:**
1. `python tests/test_numpy_parts.py` and `python tests/test_model_torch.py` from this folder.
2. `01_check_blocks` for the dataset. Adjust `model.saRadii` in `configs/datasets/{dataset}.yaml` if the balls are badly filled.
3. A smoke run in `02_train` with `OVERRIDES = ['training.epochs=1', 'training.blocksPerEpoch=32']` and `SEEDS = [42]`. Note the seconds per epoch and the GPU memory. If memory is short, use `['training.batchBlocks=2']` for every run of that dataset.

## Strcture followed

- **Variant difference:** the network input is block-relative x, y, z (scaled by half the block size), plus
 `u_tilde` as a 4th column for the uncertainty variant. `src/features.py` is the only place `u_tilde` enters.
- **Training input:** the RandLA-Net blocks: random square blocks (20 m / 40,960 points for MLS, 64 m / 32,768 for AHN3), randomly subsampled and shuffled, with a random rotation about z.
- **Network:** official SSG segmentation layout. FPS ratios 1/8, 1/4, 1/4, 1/4, 32 neighbours per ball, radii in metres per dataset, BatchNorm, dropout 0.5.
- **Optimisation:** Adam at 0.001 with weight decay 1e-4, cosine schedule, 50 epochs of 2,000 blocks (1,000 for Vaihingen), batches of 4 blocks, unweighted cross-entropy (as M1 and RandLA-Net), no validation split, last epoch checkpoint
- **Inference, mIoU, PAvPU:** exactly as RandLA-Net (every point predicted by 4 overlapping blocks, softmax summed; PAvPU with K = 30 metric neighbours and the same cached median threshold).

## Configs

`configs/base.yaml` holds the shared settings and `configs/datasets/{dataset}.yaml` the dataset-specific ones (files, block size, radii, label exclusions). The Vaihingen coordinates in the ANN feature files are not in metres (extent about 1.1 units per area), so its radii are in those units; see the note in `configs/datasets/vaihingen.yaml`.
